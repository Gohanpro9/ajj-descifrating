# ajj descifrating

ajj descifrating es un sistema de cifrado y descifrado creado por Gohanpro9 basado en sustitución de caracteres mediante símbolos y combinaciones especiales. Su funcionamiento consiste en transformar letras y números en símbolos específicos para convertir mensajes normales en texto cifrado difícil de interpretar a simple vista.

El proyecto funciona mediante una página web dedicada al cifrado y descifrado automático de texto usando la tabla oficial de ajj descifrating. El objetivo del sistema es ofrecer una forma creativa y personalizada de ocultar mensajes utilizando símbolos únicos.

Características:
- Cifrado automático de texto
- Descifrado automático de mensajes
- Sistema de sustitución personalizado
- Uso de símbolos especiales
- Diseño enfocado en mensajes secretos y experimentales
- Compatible con el sistema oficial de ajj descifrating
